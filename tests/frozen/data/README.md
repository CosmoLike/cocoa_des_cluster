# des_cluster data

Placeholder 3x2pt data set, copied from `projects/des_y3/data`: the DES Y3
unblinded 3x2pt data vector and covariance (xi+-, gamma_t, w(theta);
redMaGiC lens sample with 5 bins, Metacalibration source sample with 4
bins, 20 angular bins between 2.5 and 250 arcmin; 900 entries), the
3x2pt baseline mask, the matching n(z), and the baryon PCA and
simulation files.

`des_y3_real.dataset` points the likelihood at these files. The cluster
blocks of the 4x2pt + N analysis (cluster number counts, cluster
lensing, cluster clustering, cluster-galaxy clustering) are not in this
data set yet.
